
Build a secure, professional, and fully dynamic Alarm & Security Installation Vault (FieldSafe) supporting a Client-Site-Installation hierarchy with dynamic custom fields, secure code masking, file uploads, and maintenance tracking.
1)Client & Site Hierarchy -Organize data naturally by Client, then by Site, allowing multiple installations of any type per location.
2)Dynamic Installation Forms -Comes with Intrusion and Fire pre-configured, and includes an admin panel to add new types (like Access Control) with custom fields anytime.
3)Secure Code Vault -Sensitive fields like Installer and Master codes are masked by default with a secure 'click-to-reveal' toggle.
4)Document & Photo Manager -Upload, organize, and preview building plans, material specifications, and site photos directly under each installation.
5)Maintenance & Alerts System -Track maintenance dates, record observations, assign technicians, and see automatic alerts for systems requiring service.
6)Self-Hosting Export Ready -Clean, standard code structure allowing you to easily download the complete source code to host on your own private server.

Professional, high-security aesthetic with dark slate and safety blue accents, clean layouts for field technicians, and clear status badges.

We will build FieldSafe using a modern React and Tailwind CSS frontend with a robust relational data model. To support future installation types like Access Control or CCTV, we will build a dynamic schema engine. This allows you to define new installation types and their specific fields directly from an Admin settings panel without writing new code. The app will be fully self-contained and prepared for easy export so you can host it on your private server after testing.
